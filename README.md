# Smitha Rajappa

I build LLM applications for real business problems. I'm an AI Engineering co-op at Lennox and an MS IT Management student at UT Dallas (May 2027). Before that, I spent 7 years as a full-stack software engineer at Accion Labs.

## Selected work

- **[SLM Suitability Framework (S3)](https://github.com/smitharajappa/SLM_Research_Project)** — Benchmarked 3–8B small language models against a 70B LLM across eight enterprise use cases, and built a scoring framework that predicts when a small model can replace a large one. The main finding: task type, not model size, explains most of the performance gap. Co-authored paper, UT Dallas.
- **[Fix or Call](https://github.com/smitharajappa/fix-or-call)** — An AI repair triage app. Describe or photograph a household problem and get a diagnosis, a DIY-or-call-a-pro verdict, and steps or a cost estimate. Built on Claude with structured JSON output and conservative safety rules.
- **[RewardForge](https://github.com/smitharajappa/rewardforge)** — A product prototype of an RLHF workflow: annotate preference pairs, train a reward model, run an RL loop (PPO, GRPO or DPO) and evaluate the result.
- **At Lennox (internal):** A voice role-play sales coach, an assistant that reads equipment nameplate photos, and the LLM evaluations and guardrails behind them.
